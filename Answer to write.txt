Chit 1 – Study of Deep Learning Packages
Q1. Study TensorFlow and Keras and explain their distinct features.

Answer:

TensorFlow:
1. TensorFlow is an open-source deep learning framework developed by Google.
2. It is used to build and train machine learning models.
3. It supports CPU and GPU processing.
4. It is useful for developing complex neural networks.
Keras:
1. Keras is a high-level deep learning API.
2. It provides a simple interface for building neural networks.
3. It supports different neural network layers.
4. It works with TensorFlow as its backend.
Difference: TensorFlow provides the complete framework, while Keras makes model development easier.

2. Perform tokenization.
3. Create a vocabulary of unique words.
4. Generate context-target word pairs.
5. Convert words into numerical representations.
6. Train the CBOW model.
7. Display the predicted target word.
Example:

Sentence: "I love deep learning."

Context Words: I, deep.

Target Word: love.

Result: The CBOW model learns to predict target words using context words.
